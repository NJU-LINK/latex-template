# NJU-LINK Logo

左侧蓝紫图形沿用原始 Logo，LINK 字标在 **Quicksand Bold（700）** 的基础上
加厚笔画，保留圆润端点，并略微降低字高、收紧字距，让小尺寸页眉也清晰醒目。

- `njulink-logo-transparent.png`：透明背景，供 LaTeX 首页与页眉使用。
- `njulink-logo.png`：白底 PNG，适用于白底文档。
- `njulink-logo.svg`：可编辑版本；字标为矢量路径，左侧图形为内嵌原始位图。

PNG 与 SVG 的画布均为 2942 × 911。SVG 自带图形与字形路径，
无需额外安装字体。原始字标版本保留在 Git 历史中。

字体来源：[Google Fonts / Quicksand](https://github.com/google/fonts/tree/main/ofl/quicksand)。
